# Related Work V1

Recent HCI research has increasingly moved beyond one-shot prompt-response interactions to study AI assistants that persist across time, maintain remembered state, and participate in ongoing user tasks. In such systems, the quality of interaction depends not only on the immediate output, but also on what the system remembers about the user and how that remembered state shapes future behavior. Our work sits at the intersection of three lines of research: persistent assistants and AI memory, editable or shared representations for human-AI interaction, and interventions for appropriate reliance on AI outputs.

A first relevant thread concerns persistent assistants and remembered user state. Systems such as *Persistent Assistant* show the value of seamless, ongoing AI support for everyday decision-making, emphasizing efficient intent grounding and low-friction interaction over repeated use. Relatedly, *Memoro* explored LLM-supported memory augmentation interfaces that help surface and organize remembered information during interaction. Together, these systems establish that memory is not merely an implementation detail for AI assistants: remembered preferences, constraints, and prior interactions increasingly act as infrastructure for future assistance. At the same time, most such work treats memory primarily as a capability that enables continuity, retrieval, or convenience. It leaves relatively open how users should inspect, question, and deliberately reshape remembered state when that state becomes stale, incomplete, inferred too aggressively, or otherwise misaligned with current needs.

A second line of work argues that effective human-AI interaction requires more than prompt-only exchanges and benefits from structured, manipulable intermediate representations. Recent CHI- and IUI-adjacent work has emphasized shared or compositional structures that allow users to remain oriented, inspect AI contributions, and steer system behavior more deliberately. For example, *Canvil* frames LLM-powered experiences as something that should be designerly adapted rather than treated as fixed chat interfaces, while *Compositional Structures as Substrates for Human-AI Co-creation* argues that users need environments that support planning, iteration, inspection, and control beyond prompts and results. Similarly, IBM’s work on *Interactive Shared Representations* for GenAI-assisted hypothesis exploration shows how structured external representations can support exploration and refinement by making the interaction substrate itself available to both human and AI. Across these projects, the common theme is that intermediate structures can improve orientation, control, and iterative collaboration.

Our work builds directly on this shift toward manipulable AI state, but focuses on a specific form of intermediate representation: persistent remembered user state in an assistant. The closest prior work here is *Semantic Commit*, which studies how users update intent specifications and AI memory over time. Inspired by software engineering notions such as impact analysis, *Semantic Commit* treats memory updating as a process of semantic conflict resolution: new intent may have non-local implications for existing stored specifications, and interfaces should help users surface and resolve those conflicts. This is highly aligned with our view that persistent AI memory should not remain an opaque backend artifact. However, the emphasis of *Semantic Commit* is on integrating new intent into an existing specification and helping users reconcile state-level conflicts. Our work instead asks a complementary question: once remembered state is exposed and editable, how can users understand its downstream behavioral consequences, and does that help them calibrate reliance on future AI recommendations? In other words, prior work has begun to support updating persistent AI state, but has not fully addressed how users reason about the effects of remembered state on downstream assistant behavior during decision making.

A third major line of research concerns transparency, verification, and appropriate reliance on AI outputs. Recent CHI work has shown that users often over-rely on fluent but incorrect LLM responses, motivating interface interventions that help them judge when AI advice should or should not be trusted. *Fostering Appropriate Reliance on Large Language Models* shows that explanations can increase reliance on both correct and incorrect answers, while sources and explanation inconsistencies can reduce reliance on incorrect ones. *Effects of LLM-based Search on Decision Making* similarly finds that LLM-based systems improve speed and subjective experience, but also induce overreliance when the model is wrong; lightweight highlighting can mitigate this problem. Other work further demonstrates that reliance is shaped by presentation cues such as confidence and uncertainty. *As Confidence Aligns* shows that AI confidence affects users’ own self-confidence calibration, while *“I’m Not Sure, But…”* finds that uncertainty expression can reduce overreliance on incorrect answers. IBM’s *RELIC* likewise investigates ways of helping users inspect and verify LLM responses through consistency-oriented interaction.

This body of work is important for our framing because it makes clear that reliance is not a fixed attitude toward AI, but something shaped by interface design. However, most existing reliance-oriented interventions operate at the level of outputs: they help users assess whether a particular answer, explanation, or recommendation is trustworthy after it has already been produced. Our work instead intervenes at the state level. Rather than asking only whether users trust an output, we ask whether users can inspect and repair the remembered basis of future outputs, and whether seeing the downstream impact of that remembered state helps them rely on the assistant more appropriately. In this sense, impact preview is not simply another explanation feature. It is a mechanism for linking remembered state to anticipated behavior, potentially enabling users to debug the assistant before overreliance on a flawed recommendation occurs.

Finally, our work is adjacent to older HCI research on controllable personalization, preference elicitation, and mixed-initiative user modeling. Prior work on explicit preference elicitation, user-controllable personalization, and mixed-initiative personalization established that users often benefit when they can directly shape the parameters driving adaptive systems, rather than relying entirely on system-controlled adaptation. This literature is useful as a foundation, but our contribution goes beyond making preferences editable. We study persistent AI memory as an interaction layer whose entries are not only editable, but also linked to certainty, source, and likely downstream consequences. This distinction matters because modern AI assistants do not merely use static user preferences; they infer, persist, and reuse remembered state in ways that can silently shape future behavior.

Taken together, prior work shows that persistent assistants increasingly depend on remembered user state, that users benefit from manipulable intermediate representations, and that transparency cues can shape reliance on AI outputs. Yet these lines remain weakly connected. We still know relatively little about how users inspect and repair remembered assistant state when they also need to understand how that state shapes downstream recommendations. Our work addresses this gap by studying an impact-aware editable memory workspace for persistent AI assistants.
